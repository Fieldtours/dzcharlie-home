# dzcharlie.com — home page

The DZ Charlie home page, the 372 English site pages (`places/`), the Spanish Civil War
pages in Spanish (`es/guerra-civil/`), trip ideas (`visit/`), the stats page and the sitemap.
The guides themselves live in their own projects (Easy-company, spanish-civil-war,
into-europe); `_redirects` shows them under dzcharlie.com.

Publishing: Netlify project **dzcharlie44** is connected to this repository. Pushing to
`main` puts the change live on dzcharlie.com within a minute.
